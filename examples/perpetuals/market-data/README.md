# LifyX Perpetual Market Data

Public developer resources for working with LifyX Perpetual market data.

## Overview

LifyX Perpetuals provides decentralized perpetual trading across crypto and global markets through a self-custodial trading experience.

LifyX Perpetuals integrates Orderly infrastructure for perpetual market data, liquidity access and trading functionality.

This section contains developer examples related to perpetual market information and public trading data.

## Market Data Resources

Examples will cover:

- Perpetual markets
- Trading symbols
- Market information
- Order book data
- Funding rates
- Index prices
- Mark prices
- Open interest
- Recent trades
- Market status
- Token and asset metadata

## Planned Examples

### Get Markets

## Infrastructure

Infrastructure Provider: Orderly

LifyX integrates Orderly infrastructure to support decentralized perpetual trading, liquidity access, market data and execution functionality.

## Security

Public market data examples should never require:

- Private keys
- Seed phrases
- Wallet credentials

Never expose sensitive credentials in public source code.
